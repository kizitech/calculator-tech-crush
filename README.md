# Node.js Calculator Application

## Assignment Overview
This project demonstrates the use of different types of modules in Node.js by creating a simple calculator application. The application showcases:

1. **Built-in Node.js modules**: Using the `readline` module for terminal input/output  
2. **Third-party modules**: Using the `chalk` module for colorful terminal output  
3. **Custom modules**: Creating and using my own modules for calculator operations  

## Project Structure
The project consists of the following files:

- `calculator.js`: The main application file that handles user interaction  
- `operations/basic.js`: A custom module for basic arithmetic operations  
- `operations/advanced.js`: A custom module for advanced mathematical operations  

## Features
- Interactive command-line interface with a menu system  
- Colorful output using the chalk module  
- Basic calculator operations (addition, subtraction, multiplication, division)  
- Advanced operations (power, square root)  
- Input validation and error handling  
- Modular code structure
